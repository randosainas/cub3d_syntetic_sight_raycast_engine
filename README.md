A 42 project implementing a 3D rendering engine using raycasting. The goal is to simulate a "vision system" for a program running in a continuous loop, interpreting a 2D map into a 3D first-person view in real time.

🚀 Features
Real-time rendering using raycasting

Continuous game loop (while(1)) for frame updates

Basic collision detection and player movement

2D map parsing and environment projection

Implement texture and wall rendering

🎯 Core Principles Learned
Raycasting algorithms and 2D-to-3D projection math

Implementing a game loop and real-time rendering logic

Working with low-level graphics libraries (MiniLibX)

Memory management in C and avoiding leaks

Modular code architecture for an engine-style project

Handling event hooks and input at a system level

🛠️ Technology stack
C (C99 standard)

MiniLibX graphics library

Makefile-based build system

📌 About
This project a team project done with 0x496D7065, it is part of the 42 curriculum and is a stepping stone toward building real-time engines, focusing on software-based rendering and core computer graphics concepts.
